# Fallen.hud — Downloads

Launcher, instalador e atualizações do Fallen.hud para Windows x64.

## Baixar

**[Baixar o launcher](https://github.com/Ffrnds/FallenHUD-Downloads/releases/latest/download/FallenHud-Launcher.exe)**

1. Baixe e abra o `FallenHud-Launcher.exe`.
2. Clique em **Instalar Fallen.hud**. O launcher baixa e verifica o instalador.
3. Instale o [Npcap](https://npcap.com/#download), necessário para ler os pacotes do jogo.
4. Clique em **Abrir Fallen.hud**. Nas próximas versões, o launcher oferece **Atualizar**.

O launcher e o instalador incluem o runtime .NET. Não é necessário instalar o SDK.

Prefere instalar diretamente? **[Baixar o instalador](https://github.com/Ffrnds/FallenHUD-Downloads/releases/latest/download/FallenHud-win-Setup.exe)**.

## Atualizações

O aplicativo instalado também procura atualizações automaticamente. Se você instalou uma versão que usava o antigo
repositório de downloads, execute o novo instalador ou o launcher uma vez para migrar. Configurações e histórico
continuam em `%APPDATA%\Fallen.hud`.

O programa é instalado em `%LOCALAPPDATA%\FallenHud`. O launcher pode ser guardado na pasta que você preferir.

## Código correspondente e componentes de terceiros

Cada [versão publicada](https://github.com/Ffrnds/FallenHUD-Downloads/releases) oferece o arquivo
`FallenHud-VERSÃO-source.zip`, com o código correspondente e as instruções para compilá-lo.
As licenças e atribuições dos componentes estão nos arquivos `GPL-3.0.txt` e `THIRD-PARTY-NOTICES.txt` do mesmo release.
O repositório de desenvolvimento e seu histórico são privados.
